
# FlipKart Clone Project
Technologies used:-

Python, Django, MySQL, JavaScript, CSS, HTML

Funtionalities:-

• Developed a full-stack Flipkart clone using html, css, javascript, python (django) and mysql.

• Implemented crud operations, which includes registering new product,update user’s cart,deleting
product from cart and reading the orders and cart details.


• Also implemented google authentication, gmail notification on every order placed, razorpay payment
gateway, efficient search component.

• Hosted the application on pythonanywhere.com, optimizing for performance and security, while
integrating database management for reliable data storage and retrieval. 
## 🛠 Skills
Python, Django, MySQL, JavaScript, CSS, HTML, SDLC
